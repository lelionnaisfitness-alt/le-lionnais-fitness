# Le Lionnais Fitness — site vitrine

Ce dossier contient une première version responsive du site, avec les pages :
- Accueil
- À propos
- Les cours
- Coaching
- Contact
- Mentions légales

## Tester le site sur votre ordinateur
Ouvrez `index.html` dans un navigateur.

## Publier gratuitement avec GitHub Pages
1. Créez un compte sur https://github.com si vous n'en avez pas.
2. Créez un nouveau dépôt public, par exemple `le-lionnais-fitness`.
3. Importez tous les fichiers de ce dossier à la racine du dépôt.
4. Dans le dépôt, ouvrez **Settings → Pages**.
5. Dans **Build and deployment**, choisissez **Deploy from a branch**, sélectionnez `main` et `/ (root)`, puis enregistrez.
6. Attendez la publication : GitHub indiquera l'adresse du site dans la section Pages.

L'hébergement GitHub Pages peut être gratuit pour un site public. Une adresse personnalisée comme `lelionnaisfitness.fr` nécessite généralement l'achat du nom de domaine.

## À personnaliser avant publication
- Compléter les mentions légales (adresse professionnelle, SIRET, hébergeur, etc.).
- Ajouter le lien exact vers Instagram.
- Vérifier le numéro de téléphone, l'e-mail et toutes les informations.
- Ajouter de vraies photos si vous le souhaitez.
- Vérifier les packs affichés (4 séances : 180 €, 8 : 344 €, 12 : 480 €, 16 : 608 €) et préciser leurs conditions exactes.
- Confirmer la zone d'intervention (Tours et communes limitrophes, environ 20 km).
- Tester le site sur téléphone et ordinateur.

Cette version n'inclut pas de système de réservation ni d'envoi de formulaire côté serveur. Le formulaire de contact prépare un e-mail dans l'application de messagerie du visiteur.
